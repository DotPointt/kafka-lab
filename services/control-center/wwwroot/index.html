Kafka Lab

An interactive playground for learning Apache Kafka: a real 3-broker cluster with services in C#, Go and Python. Break it and watch what happens.

  • 🗺 Live map — messages flowing through brokers, partitions and consumer groups in real time.
  • 💥 Failures — kill brokers, cut the network, build up lag; every event has a "why?".
  • 🎓 Learning — guided scenarios, cheat sheets and flashcards.
